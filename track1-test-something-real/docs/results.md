# Results

No live Flagsmith experiment results are available yet. Local simulation and tests are implementation checks, not business findings.

Before publishing results, record: experiment URL, environment, immutable data/code version, traffic source/run IDs, sample counts, conversions, lift and credible interval, chance to beat control, split-health warnings, excluded identities, guardrail results, last-computed time, and the final decision with rationale. Attach dashboard screenshots and the demo-video URL. Allow the last operator the full ten-minute conversion window.

For synthetic traffic, publish the behaviour model and say the result depends on programmed assumptions. An inconclusive result is acceptable. Never replace missing result fields with illustrative statistics.
